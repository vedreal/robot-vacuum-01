Entry for the [make.fun bounty](https://make.fun/bounty/u-eager-stork-81-9647-the-robot-vacuum-s-funniest-9822fbd2): one line, at most 120 characters, in which a robot vacuum explains why it missed a spot.

`main.py` holds ten fresh candidate excuses, scores each against the judge's published brief (on-subject, funny at once, vacuum's own voice, vacuum-world humour, tight), and writes the highest-scoring line to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```
